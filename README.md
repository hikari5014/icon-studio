# 圖示動畫工作台 · Icon Studio

從零畫出你自己的**動態 icon**，匯出成 SVG／CSS／React／Vue／HTML／PNG。

**線上使用 → https://hikari5014.github.io/icon-studio/**

離線可用、可以裝成 App，所有資料只留在你的裝置上——**什麼都不會上傳**。

---

## 能做什麼

| | |
|---|---|
| **從零畫** | 鋼筆、方形、圓形、曲線四種工具，圖層可以疊、可以排序、可以鎖 |
| **照著描** | 匯入 JPG／PNG／GIF 當底圖，用鋼筆描出來（底圖不會被匯出） |
| **匯入 SVG** | 自動縮放置中並拆成圖層，接著就能改 |
| **配色庫** | 50 組配色。圖層存的是「角色」不是色碼，換一組整張圖跟著變 |
| **造型庫** | 20 種基本形，點一下放進畫布 |
| **動畫庫** | 18 種動畫，每一種的速度與幅度都可調 |
| **範例庫** | 24 個能直接開始改的 icon |
| **時間軸** | 把動畫**凍結在任何一個毫秒** |
| **匯出** | SVG／CSS／React／Vue／HTML／PNG／設計檔 JSON |

## 三步做一個

1. **畫** — 左邊選工具畫，或到「資料庫 → 造型」拿一個現成的來改
2. **調** — 選圖層 →「屬性」改顏色形狀，「動畫」給它一種動法
3. **匯出** — 右上「匯出」，挑格式，複製或下載

## 幾個設計上的決定

**畫布、預覽、匯出共用同一支產生器。**
`render.js` 的 `docToSVG()` 是唯一產生圖形的地方。多一條路徑就多一個
「編輯器裡對、貼出去錯」的可能——那是這類工具最難查的 bug，因為兩邊都看起來對。

**顏色存的是角色，不是色碼。**
圖層寫的是「主亮／主暗／副色／輪廓」，色碼由配色庫決定。
所以 50 組配色不需要 50 份圖，而且自己調配色時整張圖會一起變。

**外框是共用的一圈，不是每個零件各一圈。**
所有「要外框」的圖層會先用粗描邊畫一次，union 出一條連續輪廓。
逐件描邊的話，腳跟身體之間會出現一條不該有的線。

**時間軸不是裝飾。**
動畫的錯常常是「某一格不對」，而循環播放用眼睛是抓不到的。
這個專案就踩過一次：一段硬幣動畫因為緩動曲線選錯，硬幣在第 150 毫秒
就已經掉進身體裡，整段從頭到尾看不到硬幣，但 CSS 完全合法、零錯誤訊息。
最後是把動畫暫停在 150ms 去讀計算後的樣式才找到的。

## 自己跑

沒有建置步驟。

```bash
python3 -m http.server 8080
# 開 http://localhost:8080
```

用 `http://` 開才能裝成 App 與離線使用（Service Worker 不能在 `file://` 下跑）。

上線前的結構檢查：

```bash
node scripts/check.mjs
```

它守三件「壞掉不會有任何錯誤訊息」的事：版本號三處是否一致、
Service Worker 有沒有漏快取新檔案、更新日誌第一筆是不是目前版本。

## 檔案結構

```
index.html          介面骨架
styles.css          樣式
js/
  main.js           主程式（狀態／繪製／互動／面板／匯入匯出）
  render.js         幾何與渲染 ← 唯一產生 SVG 的地方
  export.js         七種匯出格式
  libs.js           配色／造型／動畫／範例四個資料庫
  version.js        版本號
  changelog.js      更新日誌
sw.js               離線快取
scripts/check.mjs   上線前檢查
```

要加一種動畫：改 `js/libs.js` 的 `ANIMS`，一筆就是一個 class 名加一段 keyframes 產生器。
要加一個範例：改同一個檔的 `EXAMPLES`。
